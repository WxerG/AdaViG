01 / OVERVIEW

Drawing is a reasoning step.
It can also be a wrong turn.

Unified multimodal models can draw diagrams as part of their reasoning. But a generated image is not always useful: an incorrect construction can become false evidence for everything that follows.

Read the abstract +

Unified multimodal models with interleaved reasoning generate both textual and visual steps as part of intermediate reasoning traces. However, generating intermediate visual reasoning steps is not always beneficial: self-generated visuals can introduce erroneous evidence that misleads subsequent reasoning, while incurring substantial computation and memory overhead. We identify two internal signals available before visual generation is complete: Generation Intent, which reflects whether the model has a concrete textual plan for what to draw, and Visual Fidelity, which measures grounding in the original input image. AdaViG is a training-free adaptive visual gating method that evaluates these signals early in diffusion and aborts a visual step when both are weak. Experiments show accuracy improvements of up to 5.7 percentage points, image-generation FLOPs reductions of 25.0%–91.0%, and wall-clock latency reductions of 15.4%–45.6%.

02 / OBSERVATIONS

Two signals.
One early decision.

I / GENERATION INTENT

Does the model know
what it wants to draw?

Attention to preceding text reveals whether the visual step follows a concrete reasoning plan. Without a plan, generation can add unconstrained details.

F / VISUAL FIDELITY

Is the drawing grounded
in the original image?

Attention to the input image reveals whether generation remains tied to the problem. Weak grounding can let the diagram drift away from its constraints.

03 / METHOD

A small intervention,
before the expensive part.

When the model triggers a visual step, run the first 5 of 50 diffusion steps. Read the two attention signals. Abort only when both are weak; otherwise, let the model finish drawing.

05 / EFFICIENCY

Stop early.
Save the remaining work.

Aborting at step 5 avoids about 90% of the denoising steps for that visual generation. Across the evaluated models and benchmarks, the paper reports end-to-end latency reductions of 15.4%–45.6%.

↳

Latency is measured on a single NVIDIA H200 (141 GB). MathVista uses its GPS subset; OlympiadBench uses its Math subset. Thresholds are tuned on MathVision testmini and fixed for evaluation.
